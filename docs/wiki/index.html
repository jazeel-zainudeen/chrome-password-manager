Password Manager Wiki

Welcome to the official developer and user documentation for Chrome Password Manager. This project is a Manifest V3 extension designed to solve the critical friction caused by native browser password autofill policies.

Key Mission: Enable reliable, secure credential selection, generation, and autofill across insecure HTTP origins, custom development ports (e.g. localhost:3000, localhost:8899), and internal routers without invasive browser warnings or broken dropdowns.

Installation Guide

Because Password Manager is designed for developers and power users, it installs as an unpacked Manifest V3 extension in Google Chrome or any Chromium-compatible browser (Edge, Brave, Arc, Opera, Vivaldi):

  1. Clone or download this repository to your local machine:
    git clone https://github.com/jazeel-zainudeen/chrome-password-manager.git
  2. Open Google Chrome and navigate to chrome://extensions.
  3. Turn on the Developer mode switch located at the top-right corner.
  4. Click the Load unpacked button in the upper-left corner.
  5. Select the repository directory (the folder containing manifest.json).
  6. Password Manager will immediately register in your toolbar. Pin the extension for quick access!

Quickstart Walkthrough

You can verify that password autofill works on unencrypted HTTP connections using the included Python HTTP test server:

cd test-page && python3 server.py

Then open http://localhost:8899/index.html in Chrome:

  • Click inside the Username or Password field.
  • The floating dropdown picker appears anchored neatly below the input.
  • Click Fill to populate the fields with a green success glow.
  • Click Sign In to verify that form submission prompts the isolated save notification.

Insecure HTTP Autofill

Modern Google Chrome enforces strict warnings on password fields hosted on unencrypted HTTP connections: "Password form on an insecure (http://) page", preventing native auto-suggestion.

Password Manager circumvents this restriction through an intelligent content script listener that operates seamlessly across:

  • http://localhost:* and http://127.0.0.1:*
  • Internal network IPs (e.g. http://192.168.1.1, http://10.0.0.1)
  • Internal microservices, staging clusters, and dev server proxies

Closed Shadow DOM Isolation

All in-page UI elements (the floating credential picker, the inline key trigger button, custom tooltips, and save banners) are mounted inside a Closed Shadow DOM (mode: 'closed'):

Security & CSS Guarantee:
1. Web page JavaScript cannot access container.shadowRoot to inspect DOM elements or sniff passwords.
2. Host page CSS frameworks (Tailwind resets, Bootstrap, high-specificity styles) cannot leak in and break the UI layout.

Vault Management & Search

Clicking the extension icon opens the sleek Dark Mode management interface:

  • Active Site Tab: Displays all logins matching the current tab's domain and origin with live search filtering and keyword highlight tags.
  • All Vault Logins: View, search, edit, copy, and delete accounts stored across any website or internal port.
  • Settings: Toggle HTTP autofill, auto-focus picker triggers, and export/import vaults in JSON or CSV format.

CSPRNG Password Generator

The extension features a built-in cryptographically secure password generator implemented in utils/crypto.js:

  • Uses crypto.getRandomValues to sample from custom entropy pools.
  • Uses a CSPRNG-driven Fisher-Yates array shuffle to eliminate positional bias.
  • Calculates real-time password strength scores (0–4) with visual feedback.

System Architecture

Component File Path Role & Responsibility
Manifest V3 manifest.json Defines minimal permissions (storage, tabs, activeTab) and content scripts.
Background Service Worker background/service-worker.js Manages tab badges, navigation state, and tab-isolated in-memory pending save storage.
Content Script content/content.js Detects inputs, injects the closed Shadow DOM picker, and handles form submissions.
Storage Utility utils/storage.js Interacts with chrome.storage.local and handles multi-part PSL domain matching.
Crypto Engine utils/crypto.js CSPRNG random character generation, Fisher-Yates shuffle, and strength scoring.

Security Hardening & Privacy

Password Manager was designed with strict security standards:

  • Zero Remote Communication: Does not connect to any telemetry, analytics, or external cloud servers.
  • No Plaintext in DOM: Passwords are never placed in data-pass or title attributes. Passwords in the in-page dropdown are masked with •••••••• until explicitly revealed.
  • Ephemeral Pending Store: Form submissions hold temporary credentials in service worker memory (isolated from page scripts) rather than shared sessionStorage.
  • Public Suffix List Matching: Aware of multi-part domains (github.io, co.uk, vercel.app) to prevent cross-tenant credential theft.

Storage Model & Persistence

All credentials persist strictly inside Chrome's private extension sandbox via chrome.storage.local:

  • Local Isolation: Web page JavaScript, third-party trackers, and other extensions cannot access the chrome.storage.local namespace.
  • Decoupled from Cloud: Operates entirely offline with zero cloud server requirements.
  • Export & Backup: Easily export your full vault to JSON or import Chrome CSV dumps directly from the Settings panel.
