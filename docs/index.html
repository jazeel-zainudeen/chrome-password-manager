HTTP & Localhost Autofill

Autofill accounts on local development servers (localhost:3000, 127.0.0.1:8000), internal staging clusters, and network consoles without SSL warnings blocking your workflow.

Built Specifically For Real Workflows

No external servers, no cloud sync lock-in, and zero interference from webpage styling.

🛡️

Closed Shadow DOM Isolation

All in-page floating dropdowns, icons, and tooltips are encapsulated inside a mode: 'closed' Shadow DOM. Host page styles cannot distort the UI, and host scripts cannot read secrets.

Closed Shadow DOM

The floating picker and inline triggers render inside mode: 'closed' Shadow roots. Page scripts cannot access secret values, and CSS resets cannot break layout.

⚡

One-Click Auto-Mapping

Intelligently recognizes complex login forms, PHP arrays (auth[user], auth[password]), and dispatches synthetic input and change events compatible with React, Vue, Angular, and vanilla HTML.

Complex Form Mapping

Autodetects login fields, AJAX forms, and nested PHP arrays (e.g. auth[user], auth[password]) without misidentifying database or server host inputs.

🎲

CSPRNG Password Generator

Built with Web Crypto (crypto.getRandomValues) and Fisher-Yates array shuffling. Generates unguessable, customizable passwords with real-time entropy scoring.

CSPRNG Generator

Generates high-entropy passwords using crypto.getRandomValues and Fisher-Yates array shuffling to avoid modulo distribution bias.

🔍

Search & Active Matching

Features instant fuzzy search across your vault with visual keyword highlighting (<mark>) and intelligent multi-part Public Suffix List (PSL) domain matching.

Local Storage Sandbox

Vault entries are stored exclusively in Chrome's sandboxed chrome.storage.local. Zero telemetry and zero third-party tracking scripts.

🔒

Privacy & Sandboxed Storage

Zero third-party trackers, zero telemetry, and zero remote servers. Everything persists inside Chrome's sandboxed chrome.storage.local.

Multi-Part Domain Awareness

Aware of Public Suffixes (e.g. github.io, co.uk, vercel.app) to prevent accidental cross-tenant credential exposure.

JSON & CSV Portability

Easily export or import your vault data via portable JSON or Chrome Password Manager CSV formats directly from the settings panel.
