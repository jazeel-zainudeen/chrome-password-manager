Unencrypted Insecure Connection (HTTP)

OmniPass Insecure Origin Test Lab

Testing password selection, autofill, and credentials capture on non-HTTPS origins where native Chrome suppresses password managers.

Notice Chrome's Default Behavior: In regular Chrome without OmniPass, clicking these password fields shows "Password form on an insecure (http://) page" and suppresses native password suggestions.
With OmniPass: Focus or click the fields below to see the modern OmniPass dropdown, one-click fill, and instant password generation!
🛠️ Local Router / Dev Server Login
Click inside the username or password field. OmniPass will automatically present saved accounts (e.g. admin / Password123!) or allow generating a strong password.

🚀 How to verify OmniPass:

  1. Open chrome://extensions, turn on Developer Mode, and click Load unpacked.
  2. Select the /home/jazeel/Projects/omnipass directory.
  3. Load this test page over http://localhost:8899/index.html.
  4. Click on the username or password input above: OmniPass floating picker appears instantly!
  5. Click Fill to populate both fields with proper input events.
  6. Try typing a new username/password and submitting: OmniPass prompts to remember the new login.
  7. Open the OmniPass extension popup to browse all vault items, generate passwords, and manage settings.
